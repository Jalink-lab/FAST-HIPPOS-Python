# All settings

Every setting of the FAST-HIPPOS window, in the order of the window: first the settings that are always shown, then those under *Advanced settings*. The second line of each name is how the setting is written in a settings file (`[section] key = value`, see [Settings files and the command line](command-line.md)). The texts are the same as the hover texts in the window.
